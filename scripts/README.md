
# Budapest Route Planner - Frontend Documentation

This folder contains the client-side code for a web-based public transport route planner. It uses MapLibre GL for map rendering, web workers for route calculations, GTFS for schedules, GTFS-Realtime feeds for live tracking and precompiled lightweight timetables.

## File Reference & Responsibilities

### Routing and Schedule Engine

* **`gtfs.js`**: Core GTFS data parser and router engine. It handles streamed zip parsing of GTFS text files, normalizes routes, stops, shapes, calendar dates, and implements the path-finding routing algorithm (calculating shortest paths combining walking and transit trips). The raw GTFS zip parsing is used in a Node.js console application for generating the daily timetables to save the client from parsing huge (>50MB) GTFS files.
* **`gtfsWorker.js`**: Background web worker that handles routing calculations and real-time data processing.
* **`stop_worker.js`**: Manages spatial indexing of stops using S2 geometry cells (`StopInfoProvider`) and extracts upcoming departure schedules (incorporating real-time adjustments) for specific transit stops. Stop indexing with S2 cells is used to only draw stops that are visible to improve performance.
* **`timetableLoader.js`**: Handles the downloading of zipped precompiled timetable components (common and daily JSON packages), extraction via JSZip, and JSON parsing to initialize daily routing states. The precompiled .json.zip-s are generated by a scheduled GitHub Workflow that uploads the files into CloudFare Pages using CloudFare's CLI (Wrangler).

### Background Processing Helpers

* **`progressLinearizer.js`**: Tracks and smoothens loading progress bars, caches progress timing history in IndexedDB to standardize progress reporting across heavy tasks.
* **`workerPromises.js`**: Utility wrapper that turns raw Web Worker message events into clean asynchronous JavaScript `Promise` structures (`WorkerPromises`).

### Real-Time Transit Tracking

* **`realtime.js`**: Manages real-time vehicle tracking via GTFS-RT Protocol Buffers. It periodically polls the GTFS-RT feed, decodes the response, processes it in gtfsWorker, then renders and updates live vehicle positions on the map.

### External Services

* **`discordIntegration.js`**: Connects to the Discord API (REST and WebSocket) to parse notification event messages (such as tracked entity coordinates and expiration timestamps) and push updates to the UI.

### Geospatial Mapping

* **`isochrone.js`**: Computes a travel-time heatmap (isochrone) and displays it on the map interface by processing pixel grid coordinate matrices via workers and rendering color-coded raster images.
* **`walk_route.js`**: Provides mathematical utility functions for calculating walking distances, durations, and spatial land-boundary clustering using Turf.js.
* **`s2_extension.js`**: Extends Google S2 geometry utilities to convert points into S2 cells, build GeoJSON polygons, and execute polygon boundary coverage searches.
* **`bridgeBuilder.js`**: A preprocessing utility script that calculates geographic bridge geometry, water body polygons, and land masses from GeoJSON data, and integrates bridge endpoints as navigable stops and connections into the route planner network.

### UI Controls & Helpers

* **`menuControl.js`**: Implements a custom MapLibre GL control (`MenuControl`) that adds a menu toggle button to the map interface.
* **`stop_ui.js`**: UI controller for rendering stop details (departure lists) and markers (stops) on the map.
* **`route_ui.js`**: UI controller for visualizing calculated journey paths and details on the map.
* **`destinations_ui.js`**: UI panel controller for managing and displaying custom tracked destination targets (interacting closely with `discordIntegration.js`).
* **`style.js`**: Defines MapLibre GL style sheets, vector tile layer configurations, colors, and visual rules for rendering the base map and overlays.

                                         v                 v
   User Actions                 [timetableLoader.js]  [realtime.js]
        |                         (Initialization)         |
        v                                |                 |
 [UI Controllers] --------+--------------+----------+      |
 (Map, Panels, Buttons)   |                         |      |
   |         ⌃            v                         v      v
 (draw)      |   [stop_worker.js]                [gtfsWorker.js]
   |         | (Spatial Area Lookups)         (Routing & Schedules)
   v         |            |                            |
 [UI]        +------------+-----(data to display)------+
